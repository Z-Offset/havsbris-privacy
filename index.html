Integritetspolicy för Havsbris

Senast uppdaterad: 14 oktober 2026

Havsbris är en app för marint väder och vind. Vi värnar om din integritet och samlar in så lite data som möjligt.

Vilken information samlar vi in?

Appen samlar inte in personuppgifter som namn, e-postadress eller kontoinformation. Du behöver inte skapa ett konto.

  • Plats (valfritt): Om du ger appen tillåtelse att använda din plats används den enbart för att hitta närmaste mätstation. Platsen skickas inte till våra servrar och sparas inte.
  • Favoriter: Dina favoritstationer och favoritplatser sparas lokalt på din enhet med AsyncStorage. De skickas inte någonstans.
  • Väderdata: Appen hämtar offentliga väder- och vinddata från tredjepartstjänster (t.ex. Open-Meteo, SMHI ViVa, RainViewer). Dessa förfrågningar innehåller inte information som kan identifiera dig personligen.

Delar vi din information?

Nej. Vi säljer, hyr ut eller delar inte någon användardata med tredje part.

Tredjepartstjänster

Appen använder offentliga API:er för väderdata. Dessa tjänster har sina egna integritetspolicyer:

  • Open-Meteo
  • SMHI / ViVa
  • RainViewer
  • OpenSeaMap

Dina rättigheter

Eftersom vi inte samlar in personuppgifter finns det ingen data att begära ut, rätta eller radera från vår sida. Du kan när som helst ta bort appen för att radera all lokalt sparad data (favoriter).

Ändringar i denna policy

Vi kan uppdatera denna integritetspolicy. Den senaste versionen finns alltid tillgänglig på denna sida.

Kontakt

Om du har frågor om denna integritetspolicy kan du kontakta oss via App Store-sidan för Havsbris eller på e-post som anges där.
